# Pokédex-Replicator / Kanto Pokédex

## Description
A Gen 1 Pokédex web application built with HTML, CSS, and JavaScript using the PokeAPI.

## Live Demo
GitHub Pages Link Here

## Features

- Displays all 151 Kanto Pokémon
- Search and Filters Pokémon names and types
- Pokémon detail modal
- Animated Pokémon sprites
- Pokémon descriptions
- Height, weight, and abilities
- Base stats with visual stat bars
- Resonsive layout

## Technologies Used

- HTML5
- CSS
- JavaScript
- PokeAPI

## Running Locally

1. Clone the repository
2. Open the project folder
3. Open index.html in your web browser

## API
This project uses PokeAPI to retrieve Pokémon data.
